# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it by:

1. **GitHub Security Advisories** (preferred): Use [Privately reporting a security vulnerability](https://github.com/Tomatio13/session-analyzer/security/advisories/new)
2. **Email**: Contact the maintainer via GitHub

Please do not publicly disclose the vulnerability until it has been addressed.

## Response Time

We aim to acknowledge security reports within 48 hours and provide a fix within 7 days for critical issues.
